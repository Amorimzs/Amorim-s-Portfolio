# 📂 Amorim's Portfolio

Seja bem-vindo ao repositório do meu site portfólio pessoal. Este projeto foi desenvolvido por mim para centralizar e apresentar meu currículo, competências técnicas, experiências práticas e projetos na área de tecnologia.

O site possui uma identidade visual moderna e de alto impacto, utilizando uma paleta baseada em tons escuros com destaques em verde neon, transmitindo dinamismo e tecnologia.

---

## 👨‍💻 Sobre Mim & Proposta do Portfólio

Sou um profissional em transição estratégica para a área de Tecnologia e Desenvolvimento de Sistemas. Meu grande diferencial de mercado é a bagagem técnica construída em eletrônica industrial (análise de diagramas, diagnósticos complexos e automação), que me proporcionou um raciocínio analítico afiado para a resolução de problemas reais de software.

Este portfólio serve como o meu cartão de visitas principal, conectando:
* **Formação Acadêmica:** Meu progresso no curso superior de Análise e Desenvolvimento de Sistemas.
* **Competências Técnicas:** Especialidades em desenvolvimento web, engenharia de software e banco de dados.
* **Experiência de Campo:** Minha sólida vivência com troubleshooting e sistemas da Indústria 4.0.

---

## 🛠️ Tecnologias e Recursos Utilizados

O desenvolvimento foi feito do zero, aplicando boas práticas de estruturação e estilização:

* **HTML5:** Estruturação semântica e limpa de todas as seções do site.
* **CSS3:** Estilização avançada com uso de variáveis de cores, animações de flutuação (`@keyframes flutuar`) e estruturação de layout moderno.
* **Bootstrap Icons:** Biblioteca de ícones vetoriais integrada para enriquecer a experiência visual da interface.
* **Google Fonts (Poppins):** Tipografia moderna e altamente legível integrada diretamente via web.

---

## 🗂️ Estrutura de Seções do Projeto

O site foi mapeado de forma estratégica para facilitar a navegação do usuário:

1.  **Cabeçalho (`<header>`):** Menu de navegação responsivo com efeitos de transição nos links (`hover`) e botão de chamada para ação rápida ("Contato").
2.  **Destaque Inicial (`.topo-site`):** Uma apresentação de impacto mostrando que meu crescimento acadêmico e profissional andam lado a lado, com uma imagem flutuante integrada.
3.  **Especialidades (`.specs`):** Cards interativos destacando minhas três grandes frentes:
    * *Website:* Desenvolvimento web e tecnologias de programação.
    * *Banco de Dados:* Configuração e modelagem de dados.
    * *Experiência Técnica:* Manutenção e troubleshooting aplicados a sistemas de automação industrial.
4.  **Sobre Mim (`.sobre`):** Descrição detalhada do meu perfil profissional e acadêmico, acompanhado de botões sociais conectados diretamente ao meu LinkedIn, GitHub e Instagram.
